# Module 1 — CLI Unit Converter

## Build & Run
```
javac *.java
java Main
```
Requires JDK 17+.

## Files
- Main.java      – entry point, menu loop, input handling (I/O only)
- Converter.java  – conversion math + bitwise permission flag decoder (logic only)

See the accompanying Word document (Module1-Core-Language-Fundamentals.docx)
for the full theory writeup and design rationale.
